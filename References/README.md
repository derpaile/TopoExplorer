# Bildreferenzen

`Generated/` enthält kontrollierte Ausschnitte für Harz, Alpen, Küste, Ruhrgebiet und Flachland. Alle Ansichten sind 960 × 640 Pixel groß, verwenden 100 Meter pro Pixel und den vollständigen Stil „Original 2025“.

`vergleich-2015-2020.png` prüft zusätzlich die geteilte Jahresansicht mit identischer Farbpalette.

Neu erzeugen und zugleich alle Kachelränder prüfen:

```sh
./scripts/verify_image_quality.sh
```

Die gleichen Gebiete sind in der App über „Referenzansichten“ direkt erreichbar.
